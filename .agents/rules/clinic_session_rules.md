# 🩺 진료 세션 산출 및 배정 규칙 (Clinic Session Rules)

이 문서에는 주차별 평일(월~금) 진료 세션 수 산출 및 업무 배정 기준이 정리되어 있습니다.
AI 에이전트 및 시스템은 이 규칙을 준수하여 진료 일정 계산, 통계 집계, 세션 검증을 수행합니다.

---

## 1. 기본 개념 및 세션 단위
- **1세션**: 오전 1회 / 오후 1회 (하루 2세션, 평일 5일 = 총 10세션)
- **가능 세션 (Available Sessions)**: 평일 10세션 중 '휴일'을 제외하고 실제 근무 가능한 총 세션 수.

---

## 2. 휴일 및 행정/유지 구분 기준
- **휴일 (가능 세션 차감)**:
  - 법정공휴일, 주말, 일반 종일/반일 휴가(연가 등)
  - **'휴무' 키워드**: 대체휴무, 지정휴무 등 '휴무' 문구가 포함된 모든 항목도 휴일로 간주하여 가능 세션 차감.
- **행정 및 예외 취급 (가능 세션 유지)**:
  - **청원휴가**: 휴일로 차감하지 않고 **'행정'**으로 분류하여 가능 세션 수에 유지 포함.
  - **시간 단위 연가 (예: 연가 1시간, 연가 2시간 등)**: 세션 전체 휴무가 아닌 시간제 연가이므로 **가능 세션에서 차감하지 않고 유지**.

---

## 3. 가능 세션 대비 필수 진료 세션 구간표

| 주간 가능 세션 수 | 필수 진료(`O`) 세션 수 | 잔여 세션 (행정 등) |
| :---: | :---: | :---: |
| **9 ~ 10 세션** | **6 세션** | 3 ~ 4 세션 |
| **8 세션** | **5 세션** | 3 세션 |
| **6 ~ 7 세션** | **4 세션** | 2 ~ 3 세션 |
| **4 ~ 5 세션** | **3 세션** | 1 ~ 2 세션 |
| **2 ~ 3 세션** | **2 세션** | 0 ~ 1 세션 |
| **0 ~ 1 세션** | **0 ~ 1 세션** | 0 세션 |

---

## 4. 업무 배치 우선순위
1. 주차별 계산된 **필수 진료 세션 수**만큼 진료(`O`)를 최우선 배정.
2. 필수 진료 세션을 충족한 후 남은 세션은 **`행정`** 및 기타 업무로 배정.
