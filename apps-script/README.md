# 가계부 Apps Script 분리·잔액전망 동기화 초안

이 폴더는 기존 단일 `Code.gs`를 역할별 파일로 분리하고, 원본 거래 시트의 신규 id를 `잔액전망`으로 동기화하기 위한 코드 초안입니다.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 기존 웹 API 요청 계약을 유지하는 진입점 |
| `LedgerConfig.gs` | 시트명·결제수단·잔액전망 설정 |
| `LedgerApi.gs` | 웹 가계부의 조회·추가·수정·삭제 처리 |
| `Utils.gs` | 날짜·입력값·JSON 응답 공통 함수 |
| `BalanceSync.gs` | 신규 id 중복 방지, 원본→잔액전망 동기화, 같은 날짜 이체 순서, 기업카드 결제기간 묶음 |
| `Triggers.gs` | 원본 시트 직접 편집 감지 및 수동 대조 함수 |

## 동작 설계

1. 웹에서 새 거래를 저장하면 원본 시트의 id를 확인한 뒤 잔액전망의 같은 id 행을 생성·갱신합니다.
2. 사용자가 원본 `기업카드`·`토스은행`·`기업은행`을 직접 편집하면 설치형 편집 트리거가 같은 id를 동기화합니다.
3. 토스·기업은행 이체는 같은 날짜 안에서 출금 행을 먼저 정렬합니다.
4. 기업카드 상세는 13일~다음 달 12일의 결제기간을 계산하여 해당 `기업카드 결제예정` 행 아래에 묶습니다.
5. `reconcileBalanceForecast()`는 누락 id만 조회하는 수동 점검 함수입니다.

## 적용 전 확인

- 현재 Apps Script 프로젝트에 만들어진 파일 이름은 맞지만, 브라우저 코드 편집기의 자동 입력이 실제 저장으로 이어지지 않는 문제로 내용은 아직 반영되지 않았습니다.
- 기존 공개 웹 앱 배포는 수정하거나 재배포하지 않았습니다.
- 적용 후에는 `installLedgerBalanceSyncTrigger()`를 한 번 실행해 원본 시트 직접 편집도 자동 반영되게 해야 합니다.
